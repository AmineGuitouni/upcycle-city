# AGENT.md

Quickstart for coding agents working on **Upcycle City** (a Unity 6 / URP first-person
city-cleanup game). This is the short version; see [CLAUDE.md](CLAUDE.md) for conventions
and [ARCHITECTURE.md](ARCHITECTURE.md) for the full system map.

## Orient yourself in 30 seconds

- Engine: **Unity 6000.6.6f1**, URP, new Input System, C#. No ECS/DOTS except a single
  Burst crowd job.
- Gameplay code: `Assets/UpcycleCity/Scripts/Runtime/` (asmdef `UpcycleCity.Runtime`,
  namespaces `UpcycleCity.*`).
- Editor-only code: `Assets/UpcycleCity/Scripts/Editor/` (scene/content builders, import rules).
- Tuning data: `Assets/UpcycleCity/Settings/*.asset` (ScriptableObjects, edited in the Inspector).
- Scenes: `CharacterCreator` → `PlayerGym` (mechanics test) → `EcosystemSandbox` (full city).

## Run / verify loop

```bash
unity open --until-ready --timeout 900      # open + import (slow first time)
unity status                                # expect state "ready"
unity command console status                # SAVE this cursor before editing
# ...make your change; let the Editor recompile...
unity command console get -- --level error  # must be clean
unity command editor.playmode start --caller plugin --skill unity-cli
unity command script eval --caller plugin --skill unity-cli '/* inspect runtime state */'
```

There are **no automated tests and no CI**. Proof = clean console + observed Play-mode
behaviour via `script eval`. Don't leave verification code or stray `Debug.Log`s behind.

If `unity command` can't connect, check for **Safe Mode** (`unity status` reports compile
errors) — fix the C# error and the Editor leaves Safe Mode on its own.

## Golden rules (break these and you'll fight the architecture)

1. **No `FindObjectsByType` in Update/hot paths.** Use static registries + `PlayerContext`
   + C# events. Register in `OnEnable`, unregister in `OnDisable`, reset statics with
   `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]`.
2. **Trash ≠ inventory.** `TrashItem` is `IGrabbable` (physics, one at a time). Only
   tools/usables/coins (`IInventoryItem`) enter `PlayerInventory`.
3. **Interactions are interface-based.** To make something interactable, implement
   `IGrabbable` / `IInteractable` / `IPickupItem` / `IToolTarget`; don't special-case
   `PlayerInteractor`.
4. **Change player stats only through `PlayerModifiers`** (keyed by source string; additive /
   multiplier / flag). Remove by source id.
5. **New tunables go in a ScriptableObject**, read live each frame — not hard-coded constants.
6. **Keep Editor builders idempotent & non-destructive.** Scenes, tags and layers are
   generated by `Scripts/Editor/*Builder.cs` / `*Setup.cs`; keep them re-runnable.
7. **Preserve mobile budgets**: global trash cap, 4 Hz ecosystem tick, Burst crowd job,
   2-tier citizen LOD, pooled audio, PC/Mobile URP renderer split.
8. **Keep `UnityEditor` out of runtime** except behind `#if UNITY_EDITOR`.

## Where things live (by task)

| Task | Start here |
|------|-----------|
| Player movement / camera / jump feel | `Runtime/Player/PlayerMotor`, `PlayerStateMachine`, `PlayerCameraController`, `PlayerConfig` |
| Grabbing / throwing / picker | `Runtime/Player/PhysicsGrabController`, `LitterPickerView`, `Runtime/Waste/TrashItem` |
| Sorting / selling trash | `Runtime/Waste/SortingCrate`, `Runtime/Shops/RecyclingBuyBack`, `Runtime/Waste/WasteStream` |

| Shops / economy | `Runtime/Shops/*`, `Runtime/Inventory/*` |
| Audio | `Runtime/Audio/*` (`SoundManager`, `GameAudioRouter`, `SoundLibrary`) |

| Character creator | `Runtime/Character/*`, `Scenes/CharacterCreator.unity` |

## Don't

- Push to a remote, or commit `.env`/secrets, without being asked.
- Delete/rename assets without their `.meta`.
- Edit `Art/` third-party packs or run `console clear`.
- Expect `docs/game_concept.md` to exist — it's referenced in comments but absent.
